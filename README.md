# nasaspaceapp

The explorer uses [Globe.gl](https://globe.gl/) for Earth and a locally generated Mars texture. Use the side arrows to switch planets. The focused planet grows and rotates; the smaller, dimmed planet is stationary and cannot be interacted with, and its markers are hidden. Drag the focused globe to spin it; zoom and pan are disabled. Select a marker to open its details. The return-to-focus control appears only when none of the focused planet's markers are visible. Earth and Mars have separate marker sets, and Earth descriptions can be cycled with the detail arrows; each Earth slide has its own Bodele image, with the background and text crossfading over black. Only the close button dismisses a detail view, restoring the previous globe position. The local Earth texture is from the [three-globe example assets](https://github.com/vasturiano/three-globe/tree/master/example/img).
